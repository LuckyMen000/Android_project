# Запуск TaskBar в Android Studio (Windows)

1. Распакуйте `TaskBar_AndroidStudio.zip` в `C:\Projects\TaskBar` или любую короткую папку без лишней вложенности.
2. Откройте **Android Studio → File → Open** и укажите **папку `TaskBar`**, в которой находится `settings.gradle.kts`.
3. Убедитесь, что установлены **Android SDK 35** и **JDK 17** (можно использовать встроенный JDK Android Studio).
4. Если Android Studio предложит **Trust Project**, разрешите открытие проекта, если доверяете исходникам в этом архиве.
5. Дождитесь **Gradle Sync**. Для первой синхронизации нужен интернет.
6. Если IDE пишет, что отсутствует `gradle-wrapper.jar`, откройте терминал Android Studio в корне проекта и выполните:

   ```powershell
   .\gradlew.bat wrapper --gradle-version 8.11.1
   ```

   Этот скрипт скачает официальную дистрибуцию Gradle 8.11.1 и сгенерирует стандартный Gradle Wrapper. Затем нажмите **Sync Project with Gradle Files**.

7. Запустите эмулятор Pixel/Android API 35 или подключите телефон с Android 8.0+, выберите конфигурацию **app** и нажмите **Run ▶**.
8. APK, после успешной сборки в Android Studio, расположен по пути `app/build/outputs/apk/debug/app-debug.apk`.

## Проверка за 2 минуты

- На экране «Сегодня» появится 6 демонстрационных задач.
- Нажмите большой круглый **+**, заполните название, категорию и дату, затем сохраните.
- Откройте **Задачи**: найдите новую задачу поиском, отметьте выполненной, затем отредактируйте.
- Откройте **Итоги**: прогресс и распределение задач обновятся автоматически.
- Откройте **Ещё**: переключите тему, перезапустите приложение, убедитесь, что настройка и задачи сохранились.
- Выключите сеть: задачи продолжат работать, а карточка «Мысль дня» покажет локальную цитату.

**Примечание:** исходники подготовлены, но APK не собран здесь: в этой среде нет Android SDK и доступа к загрузке Gradle. Проверить итоговую сборку нужно в Android Studio на вашей машине.
